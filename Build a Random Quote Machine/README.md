## 🚀 How to Run Locally

1. **Clone the repository:**
   ```
   git clone https://github.com/acheronx0577/Front-End-Development-Libraries-V8.git
   cd "Front-End-Development-Libraries-V8/Front-End Build a Random Quote Machine"
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Start the development server:**
   ```
   npm run dev
   ```

4. **Open the app:**
   - Visit `http://localhost:5173` (or the port shown in your terminal) in your browser.
